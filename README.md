# Keepsake — Digital & Branding Agency

Адаптивний лендінг креативної агенції **Keepsake**, створений із використанням сучасного фронтенд-стеку: **Vite**, шаблонізатора **Pug**, препроцесора **SCSS** (архітектура 7-1, методологія БЕМ) та автоматизованої оптимізації графіки.

🔗 **Жива версія сайту (GitHub Pages):** [https://8scarletrose813.github.io/landing-keepsake-vite/](https://8scarletrose813.github.io/landing-keepsake-vite/)

---

## 📁 Архітектура та як працює код

Проєкт побудований за модульним принципом — дані, розмітка та стилі розділені на незалежні компоненти:

- **`src/pages/`** — головна сторінка (`index.pug`), яка збирає всі секції сайту в єдину структуру.
- **`src/components/`** — окремі HTML-модулі (`header`, `hero`, `works`, `services`, `clients`, `journal`, `footer`). Зміна одного блоку не зачіпає інші.
- **`src/data/`** — файли з даними (масиви робіт портфоліо, показники статистики, відгуки клієнтів, статті журналу). У Pug-шаблонах цикл `each` автоматично генерує картки на основі цих даних (принцип **DRY** — _Don't Repeat Yourself_).
- **`src/mixins/picture.pug`** — перевикористовуваний міксин `+picture()`, який генерує адаптивний тег `<picture>` із підтримкою сучасних форматів **AVIF / WebP**, запасним **JPEG**, атрибутами `srcset` (`400w`, `800w`) та лінивим завантаженням `loading="lazy"`.
- **`src/styles/` (7-1 Pattern)** — модульна архітектура SCSS:
  - `abstracts/` — змінні кольорів і шрифтів, функція переведення `px` у `rem()` та міксини медіазапитів `@include mq()`.
  - `base/` — скидання стандартних стилів браузера та базові налаштування типографіки.
  - `layout/` — каркасні елементи сторінки (`_header.scss`, `_footer.scss`).
  - `components/` — стилі окремих секцій (`_hero.scss`, `_works.scss`, `_services.scss`, `_ui.scss`).
  - `main.scss` — головний файл, що об'єднує всі стилі через директиву `@use`.
- **`scripts/optimize-images.js`** — Node.js-скрипт на базі бібліотеки `sharp`, який бере вихідні фото з `raw-images/`, змінює їхній розмір (`400px` та `800px`) і конвертує у формати AVIF, WebP та JPEG.
- **`vite.config.js`** — конфігурація збирача Vite з плагіном `vituum` для компіляції Pug у HTML та налаштуванням шляху `base` для деплою на GitHub Pages.

## ⚙️ Інтерактивність без зайвого JavaScript (CSS-only логіка)

Фільтрація проєктів у секції **Our Awesome Works** (_All, Branding, Identity, Print, Web, Motion_) реалізована на **чистому CSS** без клієнтського JS:

- Використано приховані радіокнопки `<input type="radio">` та зв'язані з ними `<label>`.
- Перемикання активної кнопки та приховування невідповідних карток працює миттєво через псевдоклас `:checked`, селектор сусідів `~` та атрибут `data-category`.

## ⚖️ Порівняння підходів: чому обрано цей стек

| Критерій             | Класична верстка (HTML + CSS)                                            | Сучасний стек проєкту (Pug + SCSS + Vite)                                                                     |
| :------------------- | :----------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------ |
| **Розмітка**         | Дублювання однакових блоків (наприклад, 9 карток портфоліо вручну).      | Компоненти `include`, міксини `+picture` та генерація карток у циклі `each` із файлів даних.                  |
| **Стилі**            | Один великий файл, ручний підрахунок `rem`, ризик конфлікту імен класів. | Модульна структура файлів, вкладеність, функція `rem()`, сувора методологія **БЕМ**.                          |
| **Зображення**       | Важкі JPG/PNG одного розміру для всіх екранів.                           | Автоматична нарізка через `sharp` у легкі **AVIF/WebP** під різні екрани (`srcset`) + `lazy` завантаження.    |
| **Якість коду**      | Перевірка вручну.                                                        | Автоматичний контроль через **Prettier**, **Stylelint** (заборона `#id` і `!important`) та Git-хук **Husky**. |
| **Збірка та деплой** | Файли завантажуються як є без стиснення.                                 | **Vite** мініфікує HTML/CSS (зменшує вагу файлів у кілька разів) і публікує проєкт на GitHub Pages.           |

## 🚀 Команди для запуску та розробки

- `npm install` — встановлення залежностей
- `npm run images` — оптимізація зображень (AVIF, WebP, JPEG)
- `npm run dev` — запуск локального сервера для розробки
- `npm run lint` — перевірка стилів (Stylelint)
- `npm run format` — форматування коду (Prettier)
- `npm run build` — фінальна production-збірка в папку `dist/`
